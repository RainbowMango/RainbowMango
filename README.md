# Hi, I'm Hongcai Ren

I work on **Kubernetes and multi-cluster orchestration**, through open-source
development, project maintenance, community leadership, speaking, and writing.

I'm a **Karmada maintainer**, a **Tech Lead for CNCF TAG Workloads Foundation**,
and a **CNCF Ambassador**. My Kubernetes work includes approver responsibilities
in SIG Instrumentation and SIG Multicluster.
